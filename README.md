# DONS Website

Serve this folder over HTTP to run the Red House 3D animation. Each OBJ uses its matching MTL file, which maps the shared diffuse texture from `../images/house-design.png`. After the animation, drag pieces to move them; collisions transfer impact speed to other pieces, and the final-state layout returns 15 seconds after release. Motion uses zero gravity. Hover over the center of the second piece to reveal a large translucent 1962 on white; click it for a brief grain effect. Enter 1962 in the top field to open the blank white unlocked page. Three.js and its OBJ/MTL loaders are loaded from jsDelivr.
